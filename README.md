# Compressor34

Веб-приложение для компании по обслуживанию компрессорного оборудования.

**Стек:** Python, Django, MySQL, HTML, CSS, Docker Compose.

## Запуск

```bash
docker compose up --build
```

Настройки и учетные данные задаются через переменные окружения. Не добавляйте локальный `.env` в репозиторий.
